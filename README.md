# Sprint_6

## Инструкция по запуску:

### 1. Установите зависимости:

> pip install -r requirements.txt

### 2. Запустить все тесты и записать отчет:

> pytest --alluredir=./allure-results

### 3. Посмотреть отчет по прогону html

> allure serve ./allure-results

## Список файлов:
### conftest.py:
   driver() - Фикстура для подключения вебдрайвера

### data.py:
   Содержит данные для оформления заказов, список ответов на FAQ, заголовки страниц, для проверки переходов.

### urls.py:
   Адреса страниц: основная страница, страница заказа самоката, страница Дзен для проверки перехода

### requirements.txt:
   Список зависимостей для виртуальной среды.

### locators:
   main_page_locators.py - список локаторов для основной страницы
   order_page_locators.py - список локаторов для страницы заказа самоката

### pages:
   base_page.py - POM, основные методы для описания действий на страницах
   main_page.py - POM, методы, используемые в тестах с основной страницы
   order_page.py - POM, методы, используемые в тестах с страницы заказа
### tests:
   test_main_page.py:
      - test_displayed_faq_text - проверка открытия соответствующего пункта выпадающего списка раздела "Вопросы о Важном" при нажатии на стрелку
      - test_transition_by_click_scooter_logo - проверка перехода на главную страницу, при нажатии на лого Самоката
      - test_transition_by_click_yandex_logo - проверка перехода на страницу Дзен, при нажатии на лого Яндекса
   test_order.py:
      - test_order_scooter - проверка позитивного сценария заказа самоката с двумя точками входа

### allure_results:
   результаты работы Allure
